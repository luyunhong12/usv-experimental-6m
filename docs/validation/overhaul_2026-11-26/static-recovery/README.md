# 无鳍固定载荷船：静水恢复

模型/插件对应源码提交`0822d60`，固定容器同上一阶段，输入及实际插件二进制SHA256见本目录。未改变船体、控制器、物理系数或验收门槛。运行没有飞控与航向控制；只发送零推力、零舵指令。传感器渲染系统未启用，不作为视觉验收。

## 静水独立参考

使用原`fuel_equilibrium.py`的排水多面体积分函数，仅取船体三角面（没有稳定鳍），按当前SDF三个刚体的质量和重心组合求解。无液体随姿态移动，固定质量1225.6120300420837 kg，重心FLU为(-0.6575353776970434, 0, 0.4963883192483484) m。解得船体原点z=-0.21363254902592194 m、横倾约0、纵倾=-0.002857398546351174 rad，排水体积1.2256120300420836 m³。这里z是模型原点高度，不是直接测得的最大吃水。

原推进附体插件未计其自身排水浮力，故参考同样为船体包络浮力；这仍是模型限制，不能称为整船细节完全真实。

沿用`validate_hull_runtime.py`：末5秒位置/姿态误差分别小于0.01 m、0.01 rad、0.01 rad，排水体积误差小于0.02 m³。每次运行40仿真秒，增加完整结束、数值有限、采样最大间隔<0.3 s检查。两个工况均5/5通过。
