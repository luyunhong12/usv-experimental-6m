# 6 kW无鳍候选：倒车扰动和波浪响应

输入模型/插件仍为0822d60阶段，未改变物理系数。完整静水与质量依据见相邻static-recovery。此处无航向控制，无风无流，固定载荷1225.61 kg，不能替代40 kW方案的验收。

## 零舵倒车扰动

沿用原passive_stabilizer_regression的60%反推工况：100秒直线倒车、2秒±5°舵角脉冲、60秒回零舵继续反推。按实际命令发出时刻切段，复用assess_maneuvers.py的speed_rate/recovery_metrics函数。原门槛为偏航角速度回到扰动前参考±0.05°/s并持续5秒，首次恢复须≤30秒。额外验证实际舵角脉冲>2°、尾段零舵<0.1°、反推指令始终-0.6、数据连续且完整。

| 工况 | 恢复时间 | 回零后的最大额外航向变化 | 尾段偏航速度 | 尾段纵向速度 |
| --- | ---: | ---: | ---: | ---: |
| 左脉冲 | 9.081 s | 2.880° | 0.001703°/s | -0.700 m/s |
| 右脉冲 | 9.182 s | 2.756° | 0.001699°/s | -0.700 m/s |

两项均8/8通过。被动恢复允许形成新航向，不要求回到扰动前航向。不是全部油门、全部载荷或长距离倒车合格的证明。

## 随浪

沿用现有validate_wave_response的界限：完成≥65秒、数值有限、姿态<20°、浮力为正、升沉峰峰值>0.02 m且横摇或纵摇峰峰值>0.1°。各运行70秒，统计25秒后。输入为VRX波场gain=0.3、period=4 s、steepness=0，方向0和π/2；gain不等同于有效波高。波参数同时写入所有物理插件，未启动可视渲染系统，故不能声称验证了水面视觉同步。
