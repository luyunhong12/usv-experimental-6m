# 高功率倒车与几何风阻复核（2026-11-26）

本轮延续无鳍、无飞控、直接命令候选。旧默认模型不变，不放宽验收，不用航向控制补偿。这里记录四步工作及无法通过的项目，不能解释为已达到实船精度。

## 第一步：固定旧模型的倒车失稳边界

源版本 `bfb626c346d275bba83d1dddc222e24ccc9e0c3e`，原分离模型二进制及哈希、实际运行SDF、命令/遥测、分析脚本见 `evidence/reverse-scan.tar.gz`；结构化结果见 [reverse-scan.json](reverse-scan.json)。本组未使用后续风阻修改的二进制。沿用原±5°、2秒扰动，100秒建立倒车状态，60秒恢复观察窗；恢复判据仍是回到扰动前偏航率±0.05°/s并持续5秒，必须在30秒内。

| 倒车命令 | 负向扰动恢复/s | 正向扰动恢复/s | 结论 |
| --- | ---: | ---: | --- |
| 60%（上轮） | 24.015 | 24.216 | 通过 |
| 70% | 33.907 | 33.201 | 超时 |
| 80% | 51.071 | 47.638 | 超时 |
| 90% | 观察窗内未恢复 | 观察窗内未恢复 | 失败 |
| 100%（上轮） | 观察窗内未恢复 | 观察窗内未恢复 | 失败 |

这是10%间隔的筛查，只能将30秒恢复边界夹在60%和70%之间，不能声称找到了精确临界油门。油门是转速命令比例，不是轴功率比例。

满倒车三个诊断对照：

- 步长1 ms减至0.5 ms，扰动前偏航率从约0.668717变为0.668689°/s，正向扰动尾段仍约0.910797°/s、未恢复。步长不是当前主因。
- 仅将水反扭矩设零，扰动前偏航率约0.003836°/s，但扰动后尾段仍约0.619085°/s且未恢复。消除偏置不等于恢复方向稳定性。
- 仅禁用附体水动力插件，保留其几何、质量、惯性和碰撞，扰动前偏航约0.186050°/s，恢复32.494秒。附体显著影响恢复，但去掉它仍未达到30秒。此对照是不完整物理的诊断，不能作为生产方案。

两次最初的附体对照未能启动：诊断脚本错误地把 `coefficient_scale` 设为0，而插件要求其严格大于0，配置异常导致Gazebo退出；不是有效物理结果，也不是传输可靠性证据。随后改用移除该插件的隔离对照，并增加启动进程退出检查。失败日志原样保留。

## 第二步：力模型核对与修改边界

对现有纯力函数按横移速度、偏航角速度及相应加速度做中心差分，结合刚体质量、重心和惯性，构造固定姿态的平面线性系统。它包含船体分布阻力、附加惯性/科氏耦合、分离差额及附体；不等同完整六自由度稳定性证明。

| 倒车纵速/m·s⁻¹ | 原模型最慢特征值/s⁻¹ | 禁用附体水动力/s⁻¹ |
| --- | ---: | ---: |
| −1.884 | −0.127214 | −0.176213 |
| −2.27 | −0.094910 | −0.153970 |
| −2.66 | −0.062212 | −0.131382 |
| −3.05 | −0.029479 | −0.108724 |
| −3.43 | +0.002438 | −0.086605 |

结果支持：随倒车速度上升，横移—偏航耦合的衰减能力减弱，满倒车附近该平面近似出现不稳定模态。与实跑恢复越来越慢一致；反扭矩提供初始横倾/偏航偏置，附体改变稳定性，两者不是同一个问题。

本轮没有找到足以支持“增加某个阻尼系数就是真实修复”的证据。因此**不改水动力生产系数、不删附体真实侧力、不取消桨反扭矩、不限幅满油门、不增加稳定鳍**。本项完成了模型诊断，但高功率倒车合格目标尚未完成。下一步需要能约束倒车斜流导数的独立水动力证据（例如明确边界条件和网格收敛的数值拖曳/CFD），或经确认的几何方案变化；不能把线性分析反算出的“刚好通过”系数当科学依据。

理论核对依据：[Fossen船舶运动方程](https://www.fossen.biz/html/marineCraftModel.html)的惯性/科氏项结构；[MIT操纵课程](https://live.ocw.mit.edu/courses/2-154-maneuvering-and-control-of-surface-and-underwater-vehicles-13-49-fall-2004/lec8.pdf)的船体与附体方向稳定性讨论。当前分离模型的小斜流、固定湿剖面及低Froude近似边界沿用[原分离模型报告](../hull-separation/README.md)，没有因为仿真通过部分工况就取消这些限制。
