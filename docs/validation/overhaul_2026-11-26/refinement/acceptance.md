# 第四步：新风阻候选完整回归与推广判定

结论：**不推广默认船模**。22组操纵20组通过，8组载荷/环境5组通过，另补60%倒车左右扰动2组均通过。合计32组中27组通过、5组失败；另有三个左右回转半径配对检查通过。水动力系数、验收阈值不变，无鳍、无飞控、无航向保持。

实现版本 `d0ee82b707eda6f75fff28d7ee9284df7e5e02f1`；实际镜像ID、候选SDF、插件/源/判据哈希及全部数值见[结构化验收](acceptance.json)。复核所有固定输入哈希仍一致。后续文档提交不改变这个被测版本。

本轮是无GUI的动力学回归，移除了相机渲染系统以隔离物理计算；没有声称重复完成悉尼完整传感器/GUI长测、碰撞长测或实船标定。既有模型小斜流、固定湿剖面、急转大漂角、静态风压投影和经验附体参数的限制仍保留。
