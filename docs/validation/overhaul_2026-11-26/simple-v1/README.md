# 第一阶段：无鳍、固定载荷候选

新分支`vrx-vessel-rebuild`，旧版标签不变。该阶段不切换默认启动，不接飞控；旧模型与历史证据保留。

## 实际修改

`tools/modeling/prepare_simple_vessel.py`从现有基准船生成独立候选，拒绝覆盖输出目录。移除被动稳定鳍的外观、碰撞、浮力和升阻力插件；按平行轴定理扣除5.168541826718059 kg及其完整惯性，固定船体刚体质量为1166.5675789122351 kg（不是整船总质量）。固定载荷保留原初始工况的等效重量，包括原油箱初始载荷；不是把燃油重量直接删掉。仅取消其消耗和液面变化。

AzimuthPropulsion新增`energy_enabled`布尔开关，默认true兼容旧模型，候选显式false。不加载能源/油箱配置、不订阅能源故障输入、不发布能源/油量数据、不改运行惯性；机械功率、扭矩、推力随进速、转速响应、舵机限速限力、推进指令超时仍保留。理想供能不等于无限推进力。

简化候选`/usv/actuators/state`只有前六项：仿真秒、实际舵角rad、舵角速度rad/s、参考舵角rad、舵力矩Nm、瞬时机械执行器功率估计W；没有累计电耗和电池供电标志。旧模式仍有原八项。旧能源监视器/飞控入口不能直接当作新候选启动器。

复现生成：`python3 tools/modeling/prepare_simple_vessel.py artifacts/rebuild/新的试验名`。当前候选是基于旧几何的迁移产物，仍依赖旧模型作为输入；尚未完成最终配置拆分、默认入口切换或旧代码清理。
