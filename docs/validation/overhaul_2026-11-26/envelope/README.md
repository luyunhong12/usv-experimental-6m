同幅反号响应及去除反扭矩后的近零响应，支持**本模型中反扭矩引发横倾，再通过三维水动力耦合产生残余偏航**。不是舵机未回零，也不能把正常旋桨的反扭矩设零来获得漂亮直线。正常工况保留原反扭矩，不额外施加补偿力矩。

尾段关于整船重心、以船体轴表达的偏航力矩：浮力约+0.46357 N·m，船体阻力（含分离差额）−1.13126，附加惯性+0.65432，附体+0.01338，直接推力与桨水反扭矩的z分量近零。反扭矩主要沿桨轴作用，不能因其直接z分量近零而否定上述间接耦合。尾段各项偏航力矩基本平衡，但稳定偏航率不必为零。

原始审计的`net_wrench`是已记录插件外力之和，**未包含重力**，不能把其中竖直约15.4 kN当作失衡；重力作用于整船重心，不贡献该点力矩。船体坐标下的力分量也不能直接当作地面横向加速度。

本步结论是仿真因果归因，不是对实船偏航量的验证。是否可接受继续由原操纵、走廊和环境判据决定；240 s约3.56°残余航向变化仍是适用范围说明的一部分。
