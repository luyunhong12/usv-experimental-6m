# 第三步：载荷、风浪流的独立与组合筛查

使用同一最终物理插件，没有调阻尼、加鳍、加入航向保持或放宽门槛。每组120 s，除加载前进/倒车分别用+100%/−60%指令外，环境组用+55%零舵。当前结论是 **5组通过、3组偏航超限，不能推广默认模型**。

## 载荷依据

新增300 kg工程试验载荷，均匀箱体1×0.8×0.5 m，中心FLU坐标(−0.566058,0,0.8) m。不是实际设备规格。增加视觉、碰撞并把质量/惯性通过平行轴定理合并到主体，避免改变现有整船审计的三连杆定义。箱体自身主惯性22.25、31.25、41 kg·m²，不使用质点近似。

整船质量从1571.17453变成1871.17453 kg，重心z从0.49187变为0.54127 m。新静平衡z=−0.283691 m、纵倾−0.16664°；独立湿体积求解残差小于1e−7。新剖面附加量A22=609.952 kg、A26=111.000 kg·m、A66=1323.601 kg·m²；横向二次系数362.70376，沿用原Hoerner表与积分过程，没有把旧剖面直接沿用。

小纵倾通过保留船体x/y、对z作水面剪切后重算垂直截面，仍是小倾角近似；所有剖面和解算脚本都保存。没有改变未重新估算的纵向/垂向惯性及原线性阻尼。本组重点是固定载荷质量与横向水动力一致性，不是所有自由度的实船标定。

载荷箱的风阻没有独立加入现有空气阻力模型；`air_cd_area`和作用点仍沿用原船工程假设。因此加载组合组不能作为新增箱体风压已经精确建模的证明，这也是正式推广前的剩余项。

环境姿态门槛沿用10°，推进器最低湿润比例沿用0.8；各组实测最低湿润比例为1。浪组实际波面峰峰值约0.14 m，gain不是米，不称作0.3 m浪高。横流单独工况的测得水速为(0,0.3,0) m/s；组合工况平均y水速约0.3016/0.3012 m/s，包含零均值附近的波动轨道速度，不能要求每个样本等于0.3。

横风失败可复现：首轮0.250238°/s，连接确认复测0.250248°/s；加载组合首轮0.222955、复测0.222988°/s。首轮横风尾段空气力矩z约16.24 N·m。正常横风会产生偏航，不能删除风力、加任意反力矩或暗加航向保持把结果压绿；原工程门槛不因此改写。下一步需核算实际水上投影与风压中心，再判断模型预测及可用范围。

## 运行输入校验与复测

首次`current03`实际流速为0，`wave_head03`实际油门为0；`combined`控制用推进遥测未收到，独立Gazebo stats已走到295.424 s，超过目标120 s，因而停止该无效试验。三组保留原始失败数据/日志，不计作船体物理失败或通过。另一个左转工况也有输入未送达，见操纵报告。

复测先启动暂停世界，再建立订阅/发布器并确认`has_connections()`，预发命令后通过世界control服务解除暂停；仍用原运行时间、模型与判据。复测选择清单在`selected-attempts.json.gz`，没有按结果挑最好一次。原版和复测脚本各自绑定SHA256，输入错误记录在`transport-failures.json.gz`。

这些结果仅覆盖所列载荷和温和波场；固定静态剖面的分离近似没有随每个瞬时波面重新计算。不声称强风浪、任意载荷和大漂角均已验证。速度目标15 km/h目前只在原固定载荷附近达到，300 kg附加载荷未达到15 km/h，未为此提高动力参数。
