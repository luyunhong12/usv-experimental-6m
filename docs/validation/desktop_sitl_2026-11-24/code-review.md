## 人工复核边界

本机host网络使localhost互通，但不代表网络安全隔离。Compose命令仅适用于记录中的Linux/NVIDIA/X11环境。应用启动没有跨服务自动故障恢复承诺：物理端退出后另一端可能仍在等待，使用统一down停止两端。SITL重置/仿真时间回退应成对重启，不在运行中强行让旧飞控接上新时钟。

QGC灰色在线底图保留为环境问题，不能伪装通过。AUTO、RTL、LOITER等未完成的闭环验收仍明确列出。
