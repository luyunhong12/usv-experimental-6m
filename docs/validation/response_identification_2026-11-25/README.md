## 方法

复用 `./usv navigation-test <新标签> --response-only --current-east 0 --current-north 0`。独立实例43、隔离水域、关闭渲染，正常解锁后进入MANUAL，以原生RC输入激励；没有位置或航向闭环强行约束响应。RC最小/中位/最大为1100/1500/1900，死区30 us；1563/1437在死区后对应约±8.9%驾驶员油门请求，不是实际电机转速或推力百分比。MOT_THR_MIN=1、MOT_THST_EXPO=1继续映射到实际推进请求，必须读实测值。MANUAL_OPTIONS=0时手动舵角不按AUTO的矢量混控反转；左右输入用1100/1900，要求实际达到±35°附近。上述参数全部在解锁前读回核对，阶段名描述摇杆输入，不预设实际偏航方向。

总计290仿真秒。水流在整个response阶段保持设定值，结束时清零并请求HOLD/上锁。三工况为静水、北向0.30 m/s、西向0.15 m/s。流向使用固定世界坐标，船头随响应旋转，不能假定每一阶段都是横流/逆流。

诊断只有9项数据完整性/执行检查，**不能代替25项完整导航验收，更不能证明3 m保持通过**。检查包括正常解锁、导航就绪、参数读回、估计健康、有限数据、完整阶段与采样覆盖、MANUAL模式以及激励实际送达。`scope.kind=open_loop_response`区分诊断；此模式的target_speed_m_s明确为null，MANUAL不闭环控制某个目标速度。

`response.csv`列为仿真秒、累计阶段秒、阶段序号、飞控模式、实际推进请求、纵向速度、实际舵角、参考舵角、实际推力、偏航角。角度单位rad。原 `propulsion.csv`、`actuators.csv`、`energy.csv`、DataFlash与事件记录同时保留。参数、代码和镜像快照按原入口冻结。没有修改船体物理。

归档原始CSV的CRLF、构建日志尾空格及补丁上下文空格保留原字节；`.gitattributes`只对这些证据格式设置空白检查例外，不对生产源码或测试代码放宽检查。

### 证据支持的判断

- 实际舵角与已经限速的参考角t90相同；本配置参考速率0.15 rad/s、参考加速度0.3 rad/s²，机械速度上限0.2 rad/s、力矩上限100 Nm。见[工程参数](../../../ros_ws/src/usv_description/config/trial_load.json)、[参考生成器](../../../ros_ws/src/usv_simulation/include/SteeringReference.hh)。延迟主要由参考限速安排决定，不能直接推断实船舵机存在故障，也不能在无硬件依据时随意提高机械限值。
- 相同输入下三组偏航响应近似一致，主要变化是地面运动叠加流场。这支持先研究控制器如何处理漂移与执行器响应，而不是先改动水动力。
- 对旧保持日志，以请求舵角绝对值超过30°且持续至少0.5秒识别左右完整换向请求。东向0.15、西向0.15、北向0.30 m/s的相邻反向请求间隔中位数约2.895、3.830、3.115秒，分别16/20、13/15、13/16个间隔短于静水完整换舵t90的7.774秒。实际行程和初始角度可能不同，这个比较是时间尺度线索，不把所有短间隔都判定为实际换舵失败。
- 请求角与真实舵角误差P95约64.0°、67.8°、62.9°，而相对于限速参考的实际舵角基本跟随。旧保持过程的请求明显快于配置的参考响应。[命令时序与定义](hold-command-cadence.json)及各工况 `*-hold-command-tracking.csv` 保存原始PWM到请求角的换算和插值结果。
- 非零请求与非零推力符号相反的采样占比分别约7.2%、6.6%、4.4%（仅统计|请求|>0.05且|推力|>5 N）。这是反转瞬态，不能据此说稳态推进方向接反。
- 已通过保持的东向工况也有上述现象，因此这些不是超限的充分条件，更没有证明唯一根因。保持3 m问题仍未解决。

### 后续候选及筛选结果

当前飞控未设置独立转向减速度时，会使用10°/s²的转向加速度限值估计制动转速。实测从约9.4°/s到回中后基本停止转动经历约9.4秒，包含参考换舵和船体响应。因此先用 `ATC_STR_DEC_MAX=1°/s²` 作为有效转向减速的保守候选，检验提前规划转向制动是否有益。该数值不是纯机械角减速度标定，不能据此断言最优。保持其他参数和全部物理约束不变，不立即推广；必须经过原强横流3 m门槛及后续多流向复验。

该候选已完成[强流完整筛选](../yaw_deceleration_2026-11-25/README.md)：24/25，保持峰值4.093 m、RMS 2.526 m，仍不合格，未采用。正式参数未变；没有进入全流向推广验收。
