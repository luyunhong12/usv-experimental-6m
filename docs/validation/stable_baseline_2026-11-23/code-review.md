# 本轮 Code Supervisor 与人工审查

本轮生产修改限定于两个 CMake 目标的 `-O2`，没有新增保留脚本、修改 C++ 算法或物理参数。CMake语义不属于Supervisor的Python/C++注释检查；编译flags、断言状态及回归结果另行核对。full报告提供实际执行范围，不借用历史deep结果声称本轮执行了ASan/TSan/变异。

| 项 | 本轮检查 |
|---|---|
| 1 减少重复决策 | 沿用现有目标级GNU/Clang优化方式，不新增全局构建抽象 |
| 2 基础先行 | 先比较完整载荷、无GPU载荷与隔离水域，核对实际flags |
| 3 测试驱动 | 保存旧构建性能基线，再编译对照，不只断言参数存在 |
| 4 需求审视 | 目标为稳定可复现的船体平台，暂不接飞控导航 |
| 5 质疑前提 | 空CMAKE_BUILD_TYPE不代表所有目标未优化；纠正后按目标分析 |
| 6 先减后加 | 不删物理项、不降图像/点云频率，不新增运行线程或控制器 |
| 7 可验证结果 | 沿用既有物理门槛、传感器交付门槛；实时率以sim/wall报告 |
| 8 辅助工具 | 临时采样和证据整理留/tmp，运行检查复用现有入口 |
| 9 领域建模 | 区分CPU核心占用、仿真速率、GPU负载及实船真实性 |
| 10 边界纪律 | 优化仅用于GNU/Clang；其他编译器效果未验证 |
| 11 类型纪律 | C++接口、单位和浮点类型未改；实际编译flags证明没有fast-math |
| 12 幂等操作 | 新容器、新输出目录；失败记录保留，版本绑定拒绝混用 |
| 13 共享状态 | 性能工况串行且无竞争构建；功能回归使用原分区/ROS域隔离 |
| 14 修根因 | 测量实体处理及未优化热路径；不通过降低物理精度加速 |
| 15 小步验证 | quick/full、优化前后短测、惯性/接触/操纵、独立复现与长测分开 |
| 16 行为验证 | F=ma、转矩响应、实际薄鳍接触、受扰恢复及公开ROS入口 |
| 17 复杂度 | C++函数未改；full按现有复杂度/覆盖规则检查，不虚构C++ CRAP |
| 18 重复 | 仅两处已有模式的构建声明，不为两个目标增设工具框架 |
| 19 变异 | 本轮未做变异，不拿旧变异结果代替新二进制验收 |
| 20 重构 | 未改控制/物理业务结构；比较真实遥测差异并执行原验收 |
| 21 日志 | 下载失败、旧flags、前后负载、容器版本和运行证据保留 |
| 22 上下文 | 报告给结果与限制，完整原始记录在artifacts |
| 23 工作区 | 保留用户已有预览资产；不清理其他容器或改全局权限/代理 |
| 24 提交推送 | 已授权，先推可复现候选源码；完整验收后记录稳定基线 |
