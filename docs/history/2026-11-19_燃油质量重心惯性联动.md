# 燃油消耗与船体质量、重心、惯性联动

日期：2026-11-19。沿用现有中央单机工程估算与油电模型，新增运行中燃油质量联动。没有新增实船称重或油箱内部测量。

## 实现范围

能源模型的剩余燃油体积作为唯一运行输入：`质量 = 剩余体积 × 840 kg/m³`。将现有满油船体质量表中的燃油分项先减去，得到不含燃油、但包含油箱壳体和其他设备的干船体；每个物理步再加入当前液体质量、重心和完整惯性张量。

采用平行轴定理合成，包括 ixy、ixz、iyz 交叉项，不是按质量比例缩放整船惯性。改变油量还会改变液位和液体自身惯性。推进器和转向总成仍保留各自的刚体质量，不重复扣除。

对部分装油，液面按重力方向保持水平，并与油箱内腔相交求体积、一次矩和二次矩。船体横摇/纵倾后，液体重心可相对油箱移动。采用有向四面体积分、体积二分求液面；准备/参考计算使用独立凸包分解，以交叉验证几何算法。

这是**准静态自由液面模型**：适合慢耗油、静水和低速小幅姿态变化。没有动态晃荡、挡板阻尼、加速度引起的等效重力倾斜、液体相对船体运动的动量项。它不能替代 CFD、带挡板油箱试验或大幅机动液体动力学。

干船体完整参考矩阵、坐标与参数快照在 `docs/参数与数据/fuel_mass_reference.json`。修改基础质量表后会重新推导干质量；燃油参考分项和装船账必须保持一致。满油状态重新合成后与上一阶段原质量和惯性一致。

## 为什么需要物理适配层

当前 Gazebo Harmonic 的 `components::Inertial` 更改不会自动重设底层 DART 刚体。本次新增 `usv_physics` 工作区包，保留上游 Physics 系统流程，通过已有 DART 原生世界访问功能，对 BodyNode 实际调用 `setInertia`。先验证命令，再读回后端质量、重心与惯性作为应用回执；不是只改 SDF 或显示数字。

- 实际使用版本为 ROS 路径中的 gz-sim 8.15.0、gz-physics 7.8.0、DART vendor 6.13 系列。
- 没有修改系统安装或上游 VRX 源码。匹配版本的参考源码、许可及哈希在 `vendor/`；改动补丁在 `patches/gz-sim8-runtime-inertia.patch`。
- 自定义世界已自动使用 `libUsvPhysics.so`；原启动脚本自动加入库搜索路径。其他 VRX 世界要使用本船联动时，也必须选用该 Physics 系统。
- 适配当前顶层、无闭链的船模。嵌套模型、DART 焊接镜像节点、物理引擎 fluid-added-mass 路径明确拒绝，不能直接泛化给所有机器人。
- 运行时不重建模型、不清零速度、不重置转向关节。慢耗油按离开质量携带当地船速处理，忽略排气喷流反力；液面重分布的动态流体动量未建模。

参考上游接口：[gz-sim 8.15.0 Physics 系统](https://github.com/gazebosim/gz-sim/blob/gz-sim8_8.15.0/src/systems/physics/Physics.cc)、[gz-physics 7.8.0 RetrieveWorld](https://github.com/gazebosim/gz-physics/blob/gz-physics7_7.8.0/dartsim/src/World.hh)。版本和实际受力试验共同作为实现依据，不能把“设置成功”日志代替动力学验证。

## 运行、观察与维护

```bash
# 在 gazebo_sim 中
bash scripts/build.sh
bash scripts/run_hull_trial.sh headless:=False
# 另一个终端启动机组，让正常油耗驱动质量变化
python3 scripts/energy_console.py --generator on --duration 60
# 观察应用到 DART 的质量与惯性（需相同通信分区）
GZ_IP=127.0.0.1 GZ_PARTITION=usv_hull_trial gz topic -e -t /usv/fuel_mass/state
```

`/usv/fuel_mass/state` 使用 gz.msgs.Double_V，在 PostUpdate 约 10 Hz 发布。顺序：

`time, fuel_l, hull_mass, hull_cgx, hull_cgy, hull_cgz, hull_ixx, hull_iyy, hull_izz, hull_ixy, hull_ixz, hull_iyz, ship_mass, ship_cgx, ship_cgy, ship_cgz, ship_ixx, ship_iyy, ship_izz, ship_ixy, ship_ixz, ship_iyz`。

质量 kg、坐标 m、惯性 kg·m²，重心和惯性以船体 FLU 坐标表达、惯性关于各自重心。hull 数据从 DART 读回；整船数据再组合实际转向/桨 link 的位姿和惯性。这是仿真真值，不是新增真实船载称重传感器。油位仪表仍在 `/usv/energy/sensors`，保留上一阶段的误差/滤波模型。

能源控制台也显示 `sim_ship_mass_kg` 和 `sim_ship_cg_m`，名称明确表示仿真真值；失去新鲜后端质量遥测时不继续展示旧质量。

默认仍为初始 60 L。修改 `src/usv_energy/config/energy.json` 中 `initial_fuel_l` 后重新构建，准备脚本会同步初始质量、惯性和静水平衡姿态。油箱容量/密度须与能源配置一致，否则拒绝生成。不会人为放大正常油耗，短时测试的质量变化只有克级。

暂停不消耗燃油；重置应恢复配置中的初始油量和质量属性、关闭发电机。燃油消耗后，原始 `trial_load.json` 满油账和 Blender 文件保留不改，运行状态不反写到设计基准。

## 验证设计

1. 独立受力试验：无重力测试体由 10 kg 变为 5 kg，固定 10 N 载荷；测量实际线加速度并检查更新瞬间速度连续。
2. 独立力矩试验：Izz 由 3 变为 1.5 kg·m²，固定 1 N·m；测量角加速度，另外读回变化后的三维重心。
3. 几何单元检查：0/1/6/30/60 L 直立闭式解、倾斜液体与互补空间合成整箱、惯性对称与正定。
4. 真实船模：满油/半油/低油静水工况，以及机组正常耗油；将 DART 读回与独立 Python 凸包几何积分、静水求解交叉比较。
5. 暂停/重置，以及已有推进/接触回归检查。未完成的项目不计入通过。

复现命令：`python3 scripts/validate_inertia_backend.py --mode force` / `torque`；`python3 scripts/validate_fuel_mass.py --case full` / `half` / `low` / `burn` / `reset`；串行运行，避免混淆独立场景。单元检查见 `ctest --test-dir build/usv_simulation --output-on-failure` 和 `ctest --test-dir build/usv_energy --output-on-failure`。
