## 启动、依赖与代码调整

- 根 `./usv` 提供 build / run / drive / energy / test。脚本通过仓库标记定位目录，不依赖当前工作目录。
- `usv_bringup` 保存统一启动和整船 platform 配置。原 usv_* 包继续承担自己的职责。
- Python 共用计算工具移到 tools/lib；工具位置在 tool_paths.json 登记，脚本间引用改用集中定位。
- VRX 只保留一个源码副本，sources.repos 固定提交；CMake 修正 VRX 波浪头文件和 Gazebo vendor 路径，colcon 显式扫描依赖源码。
- 运行模型及材质清单重新生成，修复海浪材质相对链接；检查了 272 个 SDF 绝对资源引用，全部存在。
- 新手动入口通过现有 ROS 控制器发送指令，检查就绪、持续发送心跳并在结束时停推，避免底层工具与控制器争抢执行器。原底层 drive_boat.py 保留用于独立物理调试。
- 历史文档保留当时的判断和命令，图片/附件链接修复；当前说明从根 README 和 docs/README 进入。

## 保全与回滚

迁移前建立 `artifacts/reorganization_2026-11-21/before_reorganization.tar.gz`，包含自有源代码、设计、资料、原始测试与日志，排除可再生成的 build/install、venv、字节码及第三方 .git 元数据。它是源码/证据归档，不是整机环境镜像。

5555 个模型、资料和测试文件记录旧路径、新路径和 SHA-256，迁移后及测试结束后再次校验全部一致。索引见 [保全清单](../../datasets/manifests/preserved_files_2026-11-21.json)。历史数据中记录的绝对路径作为原始证据保留；不能把旧生成 world.sdf 原样拿到新路径直接运行，应使用当前生成工具重建场景。

需要查看旧版本时，把归档解压到另一个空目录，不直接覆盖当前项目。详细 [迁移清单](../../artifacts/reorganization_2026-11-21/moves.json)、[删除清单](../../artifacts/reorganization_2026-11-21/removed.json)、[最终保全检查](../../artifacts/reorganization_2026-11-21/preservation_final.json) 随本机数据保留。
