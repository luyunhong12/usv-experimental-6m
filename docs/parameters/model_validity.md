# 无实船数据时的模型可信范围

本项目是带工程假设的仿真平台。方程有依据、数值自洽和实船预测准确是三个不同结论；回归通过只能支持实际测过的前两者，不能替代第三者。当前生产参数不因本说明而改变。

## 各模块的依据与尚缺什么

| 模块 | 当前依据与证据入口 | 不能据此声称的结论 | 补足数据的方法 |
| --- | --- | --- | --- |
| 船体外形、浮力 | CAD派生几何，浸没网格压力/体积积分；[浮力与波压](supervisor-vessel-sdf.md) | CAD不证明实际吃水、焊接偏差或载荷 | 提供设计排水量、倾斜试验或实测静态吃水 |
| 设备质量、重心、惯量 | [逐件台账](../../ros_ws/src/usv_description/config/component_mass_ledger.json)及平行轴计算 | 计算精确不等于输入重量真实 | 厂商数据、称重、安装坐标和满空油工况 |
| 船体与附体阻力 | [阻力预算](../../ros_ws/src/usv_description/config/resistance.json)、局部相对流速与耗散检查 | 未标定各向系数、兴波阻力、鳍遮挡和反向尾流 | 多速度拖曳/自由衰减、不同舵角与倒车试验；或网格/时间收敛的CFD |
| 附加质量 | [正对角工程参数](../../ros_ws/src/usv_description/config/hydrodynamics.json)、科氏项及步长测试 | 不包含完整频率相关辐射或真实交叉耦合系数 | 强迫振荡/辐射计算；不同频率、自由度辨识 |
| 推进器、舵机 | 有限RPM、扭矩、推力曲线、35°舵程和执行器限速；[响应辨识](../validation/response_identification_2026-11-25/README.md) | 40 kW概念方案不是已采购硬件；响应辨识来自同一仿真 | 厂商四象限推力/转矩曲线、转舵负载试验、通气/空化数据 |
| 波浪、风 | VRX有限分量波谱，视觉和物理同源；风用空气相对速度施力 | 不是完整海浪谱、破碎浪/砰击或真实阵风场；5 m/s不自动确定浪高 | 给定有效波高/峰值周期/方向谱和风谱，分海况验证 |
| 燃油、电池、功耗 | [能源模型](../../ros_ws/src/usv_energy/config/energy.json)、功率/能量核算、燃油质量惯量更新 | 不代表真实续航、温升、寿命、油液晃荡或实装散热 | 效率图、放电/热试验、油箱结构与实际发电机油耗曲线 |
| 接触与传感器 | [薄鳍接触](../validation/contact_endurance_2026-11-23/README.md)、相机点云交付长测 | 不证明结构碰撞损伤、镜面反射、多径或天气噪声真实性 | 结构分析、实物接触/传感器数据与带标定的噪声模型 |

水动力方程的质量、科氏、阻尼、恢复力划分参考 [Fossen Marine Craft Model](https://www.fossen.biz/html/marineCraftModel.html)。该依据支持结构和性质检查，不为本船的具体系数提供标定。

## 15 km/h 的定量限制

按6 m参考长度，`Fn = U / sqrt(gL)`：1 m/s约0.130，15 km/h约0.543。6 m是船长参考，不是实测水线长；若水线更短，Fn更大。

[ITTC 2021常规阻力试验规程](https://ittc.info/media/11780/75-02-02-01.pdf)将Fn>0.45等情形导向高速船试验程序；[ITTC 2024高速船阻力试验规程](https://www.ittc.info/media/11846/75-02-05-01.pdf)是后续高速标定的依据。这里只作适用范围判断，不宣称本项目完成ITTC认证，也不凭Fn断言已经滑行。

因此，15 km/h保留为概念动力方案的**仿真设计点**；当前模型在该速度缺少经验证的兴波/动态纵倾阻力预测，不能把“模拟跑到15”写成真实最高航速。当前自动导航先限定约1 m/s做控制验收；MANUAL不受此导航设定限速，仍可用于明确标注的高速探索。

## 目前能做的补强

1. 参数只在原权威配置维护；测试保存模型、参数、镜像和代码哈希。
2. 保留所有失败，新增工况不改变既有门槛。
3. 采用独立变参试验检查对模型假设的敏感性。本轮[风浪与参数敏感性](../validation/control_weather_2026-11-26/README.md)使用阻尼×0.75、附加质量×1.25两个离散扰动，不是概率区间，也不覆盖所有组合、载荷、方向和故障。
4. 验收分别报告控制精度、物理/数值一致性及未标定项。没有实船数据时，不再增加无依据的修正力来“逼真”，也不靠控制器掩盖船体受力问题。

尚待外部数据的项目保持未验证状态。这一边界不能通过更多代码测试自动消除；可先将仿真平台用于算法开发和对比，不能据此作实船性能保证。
