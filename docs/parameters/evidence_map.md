# 科学依据与证据地图

最新补充：[分布式横流阻力与固定实体配平](../validation/distributed_drag_2026-11-21/README.md)。

历史专项：[零舵受力归因、镜像剖分修复、阻力分账及直接操纵](../validation/force_maneuvers_2026-11-21/README.md)。历史约 0.058°/秒和旧参考几何不再代表当前版本。

本项目没有实船测量，目标是建立物理关系可解释、参数可替换、试验可重复的工程平台。以下依据支持模型的方法选择，不构成真实船舶精度认证。最后整理：2026-11-21。

## 怎样阅读证据

1. **物理理论**说明方程为什么合理，如浮力、刚体惯性、能量守恒。
2. **设备参考**说明某型号的额定参数，不代表本船实际安装、所有工况或概念升级的性能。
3. **几何计算**从模型得到体积、面积、力臂和位置；结果取决于模型尺寸和封闭性。
4. **工程假设**补足没有测量的密度、阻力、效率、热参数等；必须保留假设和敏感性边界。
5. **仿真验证**检查实现、数值稳定性和预期趋势；不能独立证明模型等同实船。

应沿“外部方法 → 本项目参数 → 实现 → 工况与结果 → 限制”查看。历史记录不能覆盖当前配置；原始历史数据也不能因模型更新而改写。

## 方程、参数与项目验证

### 船体质量、重心和惯性

质量相加，重心为质量加权位置；各部件惯性经过坐标变换，并通过平行轴定理移到整船参考点。完整张量包含非对角项。几何体积乘密度适用于相应的实体/壳体假设，不能把空心船直接当实心金属。

[逐件台账](../../ros_ws/src/usv_description/config/component_mass_ledger.json) 是参数入口，[质量计算实现](../../tools/lib/mass_properties.py) 与 [台账过程](../history/2026-11-21_逐件台账与载荷油量风浪流验证.md) 说明计算和估算范围。材料、厚度和部分设备重量仍待实际称重；估算区间不是统计置信区间。

### 浮力与波浪压力

静水浮力的大小为排水体积乘水密度及重力加速度，作用于浮心；分布式压力通过浸水表面积分形成力和力矩。波浪响应还取决于波场、惯性和阻尼，不能仅靠上下播放动画证明随浪物理。

[静水试验](../history/2026-11-19_船体接入与静水试验.md) 包含封闭几何和静水平衡检查；[随浪方法](../history/2026-11-20_船体外观装配与随浪优化.md) 与 [历史结果](../validation/evidence/waves_2026-11-20.json) 检查静水恢复、波幅变化及不同浪向。数值解互相吻合是内部一致性，不是同等精度的实船预测。

### 船体阻力与水下附体

六自由度框架参见上表 Fossen 来源。附体采用动态压强乘浸水面积与升阻力系数，按真实浸水几何的力臂施力；力矩来自作用点，不靠额外航向控制压住偏航。附加质量采用工程近似。

[船体阻力配置](../../ros_ws/src/usv_description/config/resistance.json)、[附加质量配置](../../ros_ws/src/usv_description/config/hydrodynamics.json)、[附体配置及来源](../../ros_ws/src/usv_description/config/appendage_hydrodynamics.json) 对应 [当前专项报告](../validation/directional_stability_2026-11-21/README.md)。报告包含修复前失败、修复后结果、扰动释放、步长和系数敏感性。现有水动力系数未标定，附体与集中阻力预算仍需进一步拆分；有界响应也不等于绝对直线。

### 推进、转向与能量

桨轴机械功率满足转矩乘角速度，电输入与轴输出通过效率关联，并受到功率、转矩和保护限制。SOC 采用电流积分；油耗及发电充电受各自模型约束。

[推进参数](../../ros_ws/src/usv_description/config/propulsion.json) 和 [能源参数](../../ros_ws/src/usv_energy/config/energy.json) 应与各自历史推导一起读。6 kW 参考推进器的额定数据不能外推为经过验证的 40 kW 产品。反推比例、桨曲线、效率、电池内阻和热参数包含工程假设；[旧能源/性能基线](../validation/baseline_2026-11-21/README.md) 不能用作真实续航保证。当前速度结论以方向稳定性报告的具体载荷与动力配置为准。

### 燃油消耗与动态惯性

由油箱内准静态液面求剩余燃油体积、质心和惯性，再与其他部件组合并更新物理后端。这实现了燃油消耗引起的质量分布变化，但没有液体动态晃荡模型。

[油箱参数](../../ros_ws/src/usv_description/config/fuel_tank.json)、[推导、后端回读及力/力矩验证](../history/2026-11-19_燃油质量重心惯性联动.md)、[公开历史摘要](../validation/evidence/fuel_mass_historical.json) 构成证据链。后端更新正确并不证明油耗曲线或油箱参数来自实船。

### 传感器、接触与软件可靠性

传感器话题、坐标变换、噪声配置和失联停推属于接口与运行验证；刚体接触属于碰撞验证。它们不能替代真实传感器噪声标定、结构强度或适航验收。

入口：[WAM-V 差距改进](../history/2026-11-20_WAMV差距完善.md)、[精细碰撞](../history/2026-11-19_物理覆盖与精细碰撞.md)、[运行可靠性](../history/2026-11-21_阻力操纵与启动可靠性改进.md)。ArduPilot 和 Nav2 的集成状态单独看 [规划](../integration/README.md)，不混入当前物理验收。
