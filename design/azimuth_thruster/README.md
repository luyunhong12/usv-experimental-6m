## 模型内容

沿用原 6m 船壳、甲板和舱内布局，船尾改成中央一台整体转向推进器。外形沿用原左机参考几何、移至中线并后移 250mm，不代表任何原厂型号已支持这种改装。

安装结构包括中央艉板内外背板、安装梁、圆轴与通孔、双轴承和轴封示意、联轴套、行星架、连接盘、减速齿轮、转向电机/编码器外形及可拆防护罩。原流线支腿与横梁的干涉已修正。旧双机外部推进器隐藏归档。

转向减速器采用 30 齿太阳轮、3 个 30 齿行星轮、90 齿固定内齿圈的概念几何；模数 2mm、压力角 20°，固定齿圈下输入/输出角比为 4:1。齿面采用渐开线采样，已实现太阳轮自转、行星轮公转/自转和输出轴转向联动。未生成加工齿根圆角、热处理要求、配合公差或负载评级。该比例是动作展示方案，不是最终执行器选型。

活动线束连接固定端与转动机罩。以 65 点曲线求解 0.98m 路径，在整数角度保持采样弧长，半度和动画中间姿态进行插值检查。线缆模型包含几何随动，没有刚度、接触或真实布线认证。

螺旋桨自转与整个推进单元的左右转向分别建模。转向轴模型坐标为 (-3.624,0,0.45)m；x 向船首、y 向左舷、z 向上。船尾位于 x=-3m。

## 调整方法

控制对象：`V2_CONTROL · 推力与转角`。

| 属性 | 用途 |
|---|---|
| `steering_deg` | 推进器朝向，正值指向左舷，支持范围 ±35°。默认已打动画关键帧 |
| `propeller_demo_rpm` | 展示用桨自转速度，可直接修改；0 为停止自转 |
| `thrust_N` | 为动力学接入预留，当前不驱动船体运动 |
| `max_steering_deg` / `planetary_ratio` | 显示本次生成的范围和传动比；不是独立重建开关 |

固定角度查看：在对象的自定义属性中删除 `steering_deg` 的关键帧/动画曲线后修改数值。播放动画会覆盖该属性的手工值。不要在支持范围外强行写入属性。

[可调参数.json](数据/可调参数.json) 集中记录参数。转向限幅可在大于 0°、不超过 35°的范围内调整，活动线束长度可调整，桨展示转速可调整。齿数、模数、齿宽等为高级结构参数；更改后必须重建并通过几何检查，不能只改文字就当机构已经匹配。超出当前壳体和布置边界时脚本会拒绝生成。

重建入口：

```bash
bash 第二船体/脚本/重建第二船体.sh
```

从项目根目录运行。可用 `BLENDER_BIN` 指定 Blender；需要 Python 和 ffmpeg。脚本依次从第一船体原文件派生、精修、细化、补齐联动、校验并渲染，仅写第二船体目录及临时渲染目录。重建会覆盖第二船体中的手工修改，手工调整前自行另存工作文件。

查看内部时，在 Outliner 隐藏 `V2细化 · 可拆防护罩` 集合。若还要看齿轮啮合，可暂时隐藏转向电机包络，或直接看齿轮检查图。当前预览保留总览、近景、齿轮检查图和 GIF/MP4 动作演示。

## ArduPilot 与仿真接口

[vector_thrust.py](仿真接口/vector_thrust.py) 提供归一化方向指令转换、带限幅和速率限制的转角更新、推力与偏航力矩计算，并能从本模型 FLU 坐标转换到 FRD。调用者必须给定标定后的推力、实际重心以及执行器速率。没有把 kW 或油门比例猜成推力，没有沿用旧双机质量预算。

接口输出 Fx=T cosδ、Fy=T sinδ、Mz=(x轴-x重心)Fy-(y轴-y重心)Fx。前进时，艉部向左的推力使船首向右转；反推时力矩反号，需由控制器处理倒车方向语义。

后续可使用 Rover 的 Boat/矢量推力方案。官方配置关系为 FRAME_CLASS=2、转向输出功能 26、油门输出功能 70；MOT_VEC_ANGLEMAX 必须按实际最大偏转角标定。当前没有写入飞控、连接硬件、启动 SITL 或建立完整三自由度水动力模型。
