## 目录

01_模型：最终模型及两种查看姿态。02_图片：拆解、开盖、联锁近景。03_说明：功能、选型、接线与未决项。04_依据与数据：质量/接线/检查记录、原厂资料、原始设计依据。05_现场核验：仍有用的测量样板和检查表。06_维护脚本：拆解图重建和静水预算工具，不包含历次试排生产脚本。

满油预算约 1273.9 kg，重心 z≈0.489 m；摄像头/雷达未重新安装。原始依据里的旧质量、旧布置不能覆盖这一版；现场排气旧底数工具仅用于认点及测量记录，最终判断需同步最新质量。历史仿真结果不作为当前模型验证依据。

项目根目录仍保留 Blender 连接工具和原版 VRX 源码环境；它们不是多个船模版本。本次没有启动仿真。删除的中间文件路径和字节数见[清理记录](清理记录.json)。
